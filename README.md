# modelagemconceitual-galeratech
Modelo conceitual de um sistema de pet shop, representando as entidades Pet, Tutor, Loja, Funcionário, Serviços e Atendimento, além de seus relacionamentos. O diagrama organiza as principais informações necessárias para gerenciar animais, clientes, serviços e atendimentos, servindo como base para a criação de um banco de dados.
